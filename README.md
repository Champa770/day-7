Colors — ways to specify them
​
Named colors — easy but limited (~140 names)
Hex — most common in real projects, #RRGGBB
rgba() — useful when you need transparency (the 4th value, 0 to 1)
hsl() — useful when you want to tweak lightness/darkness of the same hue without recalculating hex

Typography
Font family:
​
Multiple values = fallback list. If Arial isn't available on the user's system, it tries the next, ending with a generic family (sans-serif, serif, monospace) as a safety net.
Font size:
​
px = fixed. rem = relative to the <html> root font size (usually 16px by default) — scales better across devices, more commonly used in real projects. Don't need to master this today, just know both exist.
